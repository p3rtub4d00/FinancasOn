# FinancasOn

Sistema de controle financeiro pessoal, responsivo e instalável como PWA.

## Stack
- Node.js + Express
- MongoDB + Mongoose
- HTML/CSS/JavaScript
- PWA com Service Worker

## Render
Crie um Web Service apontando para este repositório.
- Build: npm install
- Start: npm start
- Environment Variable: MONGODB_URI = sua string de conexão do MongoDB Atlas

O projeto já inclui render.yaml para facilitar a configuração.

## Funcionalidades iniciais
- Dashboard com saldo, receitas, despesas e parcelas
- Cadastro de receitas
- Cadastro de despesas
- Compras parceladas
- Categorias
- Exclusão de lançamentos
- PWA instalável em celular
- Interface mobile-first
